使い方
1. ProjectPanel の RobotExpressive.glb を SceneView にドラッグして配置します。
2. 配置したオブジェクトに SkinnedAnimation コンポーネントがなければ追加します。
3. SkinnedAnimation の「クリップ」で Idle、Walking、Running、Punch などを選びます。
4. Play で再生します。編集中に確認する場合は編集時再生を有効にします。
5. Timeline では「骨アニメーション」トラックでこのオブジェクトを対象にし、
   再生するクリップ名を指定して動作切り替えを確認できます。

収録クリップ（名前は大文字・小文字を区別します）
Dance     : ダンス
Death     : 倒れる
Idle      : 待機
Jump      : ジャンプ
No        : 否定
Punch     : パンチ
Running   : 走行
Sitting   : 座る
Standing  : 立つ
ThumbsUp  : サムズアップ
Walking   : 歩行
WalkJump  : 歩行ジャンプ
Wave      : 手を振る
Yes       : 肯定

GLB内にスキンと14クリップを収録。外部のテクスチャやバッファファイルは不要です。
