RobotExpressive / 踏み込みパンチのTimelineサンプル

■ 最初の確認
1. Main.scene.jsonを開き直します。
2. Playを押すと、RobotExpressiveが1回攻撃します。
3. GameViewをクリックし、Eキーを押すと同じ攻撃を再実行します。
4. 攻撃中のEキーは無視します。待機へ戻ってから押してください。
5. Consoleの「RobotPunch」で時刻の通知と、的への命中通知を確認します。

Play中だけ、RobotAttackDemoがCamera3Dを全身と的が見える位置へ動かします。
Sceneに保存されているカメラの位置と設定は変更していません。
カメラを自分で操作する場合は、RobotAttackDemoのframeCameraOnPlayをOFFにします。

■ タイムラインを開く
1. HierarchyでRobotExpressiveを選びます。
2. TimelinePlayerの「タイムラインを編集」を押します。
3. 上部の再生対象がRobotExpressiveになっていることを確認します。
4. 上部の再生・停止・時刻編集で動きを確認できます。
5. クリップの四角をクリックすると、そのクリップの詳細が表示されます。
6. 変更後はタイムラインを保存します。割り当てを変更した場合はSceneも保存します。

編集プレビューでは骨アニメーション・移動・判定区間・火花を確認できます。
C#スクリプトのEキー入力と命中ログはPlay中に確認してください。

■ 収録トラック（全体1.6秒・60FPS基準）
01 待機 → パンチ → 待機
  Idle  : 0.00～0.20秒
  Punch : 0.15～約0.983秒
  Idle  : 0.90～1.60秒
  クリップを少し重ね、ブレンドイン・ブレンドアウトで姿勢をつなぎます。

02 正面へ踏み込み・元の位置へ戻る
  0.00～0.15秒 : 開始位置で待つ
  0.15～0.40秒 : 正面の+Z方向へ0.6移動
  0.40～1.00秒 : 踏み込んだ位置を保持
  1.00～1.45秒 : 開始位置へ戻る
  1.45～1.60秒 : 開始位置で待つ
  移動方式は区間移動です。各区間の位置は開始姿勢からの到達位置で、加算量ではありません。

03 右手の攻撃判定
  0.34～0.57秒だけRobotAttackHitboxのCollisionを有効にします。
  Palm2.Rボーンへ追従する半径0.55の球で、押し戻しを行わないTriggerです。
  Hand.Rはこのモデルではメッシュ名のため、追従には実際の骨名Palm2.Rを使っています。

04 パンチの火花
  0.40秒から1回だけ発生します。
  CPUパーティクル32個、寿命0.18～0.32秒です。
  色・不透明度・大きさを寿命で変え、発光を徐々に弱めます。
  この火花はパンチの演出として時間で発生します。命中通知とは独立しています。

05 C#への時刻通知
  AttackStart : 0.00秒
  Impact      : 0.40秒
  AttackEnd   : 1.55秒
  Impactは時刻の目印です。実際の命中はOnCollisionEnter/Stayで判定します。

■ 割り当て
  アクター     : RobotExpressive
  衝突判定     : RobotAttackHitbox
  エフェクト   : RobotAttackSparks
  アクターの保存名はActor、衝突判定はHitbox、エフェクトはEffectです。

■ 編集する場所
攻撃全体の速さ
  TimelinePlayerの「再生速度」を変更します。

攻撃判定の発生時刻・長さ
  03のクリップの開始時刻と再生時間を変更します。

判定の大きさ・位置
  RobotAttackHitboxのCollisionの半径、Transformのローカル位置を変更します。
  ボーンへの追従はJointAttachmentで設定しています。

踏み込み距離
  02のクリップの移動設定で、前進と保持の区間のZを同じ値に変更します。
  戻る区間の到達位置は0のままにします。

火花の色と寿命
  RobotAttackSparksのParticleSystemでフェーズの寿命、寿命による色、発光を変更します。

ダメージなどのゲーム処理
  RobotAttackHitboxDemoが接触を親のRobotAttackDemoへ渡します。
  RobotAttackDemo.RegisterHitで的以外と重複接触を除き、1攻撃につき1回だけ命中を通知します。
  RegisterHitの命中ログの位置へ、ゲーム固有のダメージ処理を追加できます。

■ 停止と再実行
攻撃終了後もIdleを再生します。
途中停止やスクリプトの無効化では、判定と粒子を片付けます。
Eキーで再実行する前に開始姿勢を復元するため、確認を繰り返しても位置がずれ続けません。
