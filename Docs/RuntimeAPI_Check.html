C# 実行時API・Editor確認手順

Sandboxの GameAssets/RuntimeAPI/RuntimeAPIDemo.cs で確認できます。既存Sceneの配置や照明は変更していません。

1. 確認用Entityを用意

  1. Sponza.scene.jsonを開き、空のEntityを1個作ります。
  2. RuntimeAPIDemoを追加します。Inspectorの「確認するCamera」にGameViewを描くCamera、「確認するMeshRenderer」に色が分かりやすいMeshを指定します。
  3. 必要に応じてParticleSystemと、Cameraの出力に使うRenderTextureを指定します。Particleには最低1個のPhaseを用意してください。
  4. 「CSVファイル」「JSONファイル」に同じRuntimeAPIフォルダーのRuntimeAPIDemo.csv／RuntimeAPIDemo.jsonを指定します。
  5. 「Pass名」をCameraのRenderPassesに存在する名前へ合わせます。既定値はBloomです。
  6. Playし、GameViewをクリックしてキー入力を有効にします。他のScriptが同じキーを使う場合は一時的に無効にしてください。

2. キーごとの確認

キー確認内容期待する結果
F6製品FPS上限30→60→120→未制限。Consoleに希望値とEditor出力上限が出ます。Editor自身のFPS制限は別なので、製品上限と同じFPSになるとは限りません。
F7RT影希望値が切り替わります。GPU非対応時はRTを有効にせず既存の代替経路を使います。
F8Camera・Material・ParticleCameraの色補正、指定MeshのBaseColor、Particleの色と発光が変化します。Cameraのポストプロセスを有効にしてください。
F9Camera固有のPass指定Passの有効・無効が切り替わります。同じRenderPasses Assetを使う別Cameraには波及しません。BloomはHDRの明るい物体で確認します。
F10RenderTexture256×256と512×512を切り替えます。同じAssetを参照するCamera出力とMaterialで確認します。
F11CSV／JSONCSVの行数・日本語、JSON往復の値と保存先がConsoleへ出ます。ユーザー保存先にRuntimeAPIDemo.jsonが作られます。
F12明示保存現在のゲーム用設定をユーザー設定へ保存します。次のPlay／製品起動で再利用されます。

3. Stopと再起動

  1. F12を押さずに各設定を変更し、Stopします。編集用WorldのComponent値とPlay前のProject設定に戻ることを確認します。
  2. Material AssetやRenderTextureの実行用上書きも戻ることを確認します。Scene／元Assetのファイルは実行時APIから自動保存しません。
  3. 明示保存を試す場合はF12を押してからStop→Playします。保存済みのゲーム設定が再適用されることを確認します。
  4. 保存済み設定をリセットする場合は、Scriptから GraphicsSettings.ResetToProjectDefaults() の後に SaveUserSettings() を呼びます。EditorではPlay開始前の設定が復元基準です。

4. APIの使い方

var settings = GraphicsSettings.GetSettings();
settings.rayTracingShadows = true;
settings.doubleBuffering = true;
GraphicsSettings.ApplySettings(settings);
Application.targetFrameRate = 60; // -1: 未制限

var effective = GraphicsSettings.GetEffectiveSettings();
Debug.Log(effective.rayTracingShadowsEnabled);

var pass = camera.renderPasses.FindPass("Bloom");
pass.SetFloat("intensity", 2.0f);

var rendering = camera.GetRenderingSettings();
rendering.renderPasses.FindPass("Bloom").outputs[0].widthScale = 0.5f;
camera.SetRenderingSettings(rendering);

var particle = particles.GetSettings();
particle.phases[0].GetEmissive().startIntensity = 4.0f;
particles.SetSettings(particle);

var rows = CsvUtility.Parse(csvAsset.text, true);
var save = JsonUtility.FromJson<SaveData>(jsonAsset.text);
File.WriteAllText(Path.Combine(Application.persistentDataPath, "save.json"),
    JsonUtility.ToJson(save, true));

取得した複合設定はSnapshotです。編集後にSetSettings／SetRenderingSettingsを呼びます。CameraのAssetを差し替えた場合や再読込後は、Snapshot・Pass参照を取得し直してください。RenderTextureを含む共有Assetの変更は、同じAssetを参照する全対象へ反映されます。

5. 公開範囲

分野C#の入口
描画・FPS・出力サイズGraphicsSettings、Application.targetFrameRate、Screen.SetResolution。希望設定と実際の対応状況を分離しています。
入力・Audio・衝突InputSettings、AudioSettings、Physics.IgnoreLayerCollision／GetIgnoreLayerCollision。衝突の番号はNEMEngineのCollisionタイプです。背景入力設定はゲーム更新自体を停止する設定ではありません。
Componentの単純値生成Binding。位置、色、数値、列挙、Asset／Entity参照など。存在しないComponentや異なるSceneへの保存参照を拒否します。
Camera色補正・露出などのプロパティ、renderPasses、GetRenderingSettings／SetRenderingSettings。
RendererMaterialInstance、Material.parameters、MeshRendererのSubMesh設定、RenderTexture.Resize。
Animation・Particle・CurveAnimatorのGroup設定、ParticleSystem.GetSettings／SetSettings、各Phase／Module／Curve設定。
Buffer・複合形状既存のCollision形状・Canvas配置・Spline API、FlipbookAnimation.tileColumns。
ファイルTextAsset、CsvUtility、JsonUtility。外部保存はSystem.IOとApplication.persistentDataPathを使います。

Meshインポート、ShaderGraphのノード編集、照明の事前計算、EditorのLayout・Gizmo・編集時プレビューはゲーム用APIの対象外です。実行内部のcacheや計算済み行列を直接書き換えるAPIも追加しません。

6. 製品での確認

  1. 確認用ScriptのCSV／JSON参照をSceneへ保存します。
  2. そのSceneをBuild対象へ含めて製品Buildします。
  3. 製品でF11を押し、CSV／JSONが読み込めることと、ユーザー保存が成功することを確認します。
  4. F6・F7・F12で設定を変えて保存し、終了→再起動して保存値を確認します。

TextAssetは参照されたファイルを配布対象に含めます。スクリプト内にファイル名を文字列で書くだけではAsset依存になりません。一般の.jsonとEngine専用の.scene.json／renderpasses.json等は別のAsset種別です。
