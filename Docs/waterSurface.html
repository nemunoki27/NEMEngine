揺らぐ水面 Shader Graph

2枚のシームレスなコースティクス模様を異なる方向へ流し、青い水面、明るい屈折模様、Fresnel、法線の揺らぎを組み合わせる手順です。

対象: NEMEngine Shader Graph / Primitive3D / 2026-08-01時点

現在の機能で作れるか

作成できます。 Texture2D、UV、Time、Tiling And Offset、演算、Smoothstep、PBR Surface、Fresnel、Unpack Normal、Vertex出力が実装済みです。専用Water Shaderや新しいRender Passは、この参考画像に近い見た目を作るだけなら不要です。
現在できること
水色のPBR面、流れるコースティクス、完全な時間ループ、透明度、Fresnel、法線の揺れ、小さな頂点波。
別途必要なもの
空間的に継ぎ目のないコースティクスTexture。法線も動かす場合はシームレスなWater Normal Texture。
専用機能なしで難しいこと
物理的に正しい屈折、波面に追従する焦線計算、海岸線のDepth Fade、FFT海洋、平面反射。
今回の推奨
最初はOpaqueで模様を完成させ、必要な場合だけTransparentへ切り替えます。
重要: Simple NoiseとVoronoiだけでも試作できますが、現在の実装は指定秒数で元の模様へ戻る周期Noiseではありません。正確なループを優先する場合はシームレスTexture方式を使用してください。

今回作成する見た目

水面の色とコースティクス模様を別に考えます。模様は同じTextureを2回Sampleし、拡大率と移動方向を変えて重ねます。同じ画像を使用しても、重なりが一定にならないため反復感を抑えられます。

UV Layer A→ Caustics Sample A+ Caustics Sample B→ Maximum→ Smoothstep→ Base Color / Emissive 
uvA       = UV * TilingA + frac(Time * FlowA)
uvB       = UV * TilingB + frac(Time * FlowB)
raw       = max(Texture(uvA).r, Texture(uvB).r)
mask      = smoothstep(Threshold, Threshold + Softness, raw)
water     = lerp(DeepColor, ShallowColor, saturate(raw * 0.35))
caustics  = CausticsColor * mask * CausticsIntensity
BaseColor = water + caustics
Emissive  = caustics * EmissiveStrength

必要なAssetとEntity

1. コースティクスTexture

  • 上下左右が連続するグレースケールTextureを用意します。
  • 明るい線、暗い水面という構成にします。逆の場合はGraphでOne Minusを挟みます。
  • 推奨解像度は512×512または1024×1024です。
  • 保存先例: GameAssets/Textures/Water/waterCaustics.png

エンジン標準のProject/Engine/Assets/Textures/DefaultEffect/Noiseでも試作できますが、全Textureのシームレス性は保証されません。完成版では専用Textureを推奨します。

2. Water Normal Texture

法線の揺れを追加する場合だけ必要です。DirectX形式のNormal Mapを用意し、上下左右が連続するようにします。保存先例はGameAssets/Textures/Water/waterNormal.pngです。

3. 水面Primitive

  • EntityへPrimitiveRendererを追加し、形状をPlane、描画空間をWorld3D、軸をXZにします。
  • 基本表示だけなら分割X/Yは1で十分です。
  • 隣接Planeへ模様を連続させる場合、各Planeで同じUV密度を使います。
  • Vertex変形を使う場合は分割X/Yを32にします。32×32分割では1089頂点、2048三角形が生成されます。

4. Graph作成先

GameAssets/Materials/Water/waterSurface.shadergraph.json

基本Graphの作成

1. 共通ノード

UVとTimeを1つずつ追加します。出力は複数ノードへ接続できます。

2. Layer Aを作る

Time.Time→ Multiply × FlowA→ Fraction→ Tiling And Offset.Offset
UV.Output→ Tiling And Offset A→ Sample Texture 2D A.UV
Tiling And Offset A
UVにUV.Output、TilingにTilingA、OffsetにFractionの出力を接続します。
Sample Texture 2D A
TextureにCausticsTexture、UVにTiling And Offset A.Outputを接続します。
使用出力
Sample Texture 2D AのRを使用します。

3. Layer Bを作る

Layer Aと同じ構成を複製し、TilingB、FlowBへ差し替えます。Textureは同じCausticsTextureを接続します。

Time.Time × FlowB→ Fraction→ Tiling And Offset B.Offset→ Sample Texture 2D B.R
Rotateを使わない理由: 任意角度でUVを回転すると、UV境界の座標差が整数でなくなり、繰り返し配置したPlaneの境界で模様が一致しない場合があります。1枚の有限PlaneだけならLayer BへRotateを加えても構いません。

4. 2枚を合成して焦線Maskを作る

  1. Maximumを追加し、AへSample A.R、BへSample B.Rを接続します。
  2. Addを追加し、ThresholdとSoftnessを接続します。これがSmoothstepのEdge 2です。
  3. Smoothstepを追加します。Edge 1へThreshold、Edge 2へAdd、InputへMaximumを接続します。
  4. Smoothstep.OutputをCausticsMaskとして後続処理に使います。
Sample A.R↘ Maximum→ Smoothstep→ CausticsMask Sample B.R↗

線が暗く背景が白いTextureの場合は、各SampleのR直後にOne Minusを追加します。線が太すぎる場合はThresholdを上げ、硬すぎる場合はSoftnessを上げます。

5. 水色と焦線を合成する

  1. Sample A.RとSample B.RをAddし、0.25をMultiplyしてSaturateします。
  2. LerpのAへDeepColor、BへShallowColor、TへSaturateを接続します。
  3. CausticsColor × CausticsMask × CausticsIntensityをMultiplyで作ります。
  4. Lerpの水色と焦線色をAddし、PBR SurfaceのBase Colorへ接続します。
  5. 焦線色 × EmissiveStrengthをPBR SurfaceのEmissiveへ接続します。
DeepColor / ShallowColor→ Lerp+ CausticsColor × Mask × Intensity→ PBR Base Color

空間と時間をシームレスにする

空間シーム

  • 上下左右が一致するTextureを使用します。
  • SamplerのAddress U/V/WをMODE_WRAPにします。
  • 隣接PlaneがUV 0から1を共有する場合、Tilingは2、3、4などの整数にします。
  • World Scaleが異なるPlaneを並べる場合、同じUV密度になるようPrimitiveのSizeかTilingを合わせます。

20秒で完全に元へ戻す

TextureはUVが整数分移動すると同じ位置へ戻ります。各Flow成分について次の条件を満たします。

Flow.x * LoopSeconds = 整数
Flow.y * LoopSeconds = 整数
LayerFlow20秒後の移動結果
A(0.05, 0.05)(1, 1)元のSample位置へ戻る
B(-0.05, 0.05)(-1, 1)元のSample位置へ戻る

FractionをOffset前へ入れることで値を0から1付近に保ち、長時間実行時の大きなUV座標も避けられます。Fractionが0へ戻る瞬間もMODE_WRAPなら同じTexel位置なので見た目は飛びません。

ループしない設定: FlowAを(0.037, 0.021)のような任意値にすると20秒後の移動量が整数にならず、録画やタイトル画面のループ境界で模様が飛びます。

Fresnelを追加する

  1. World NormalとView Directionを追加します。
  2. Fresnel EffectへNormal、View Direction、FresnelPowerを接続します。
  3. Fresnel × FresnelStrength × CausticsColorを作り、Emissiveへ加算します。
  4. Transparent時はLerp(Opacity, 1.0, Fresnel)をOpacityへ接続すると、斜めから見た輪郭が濃くなります。
World Normal + View Direction→ Fresnel Effect→ × Strength × Color→ Emissive / Opacity

法線も揺らす

コースティクス模様だけでは輪郭と反射像は平面のままです。Water Normal Textureを同じように2方向へ流すと、水面らしいハイライトになります。

  1. WaterNormalTextureをTexture2D、NormalStrengthをFloatの公開パラメータとして追加します。NormalStrengthは0.35から開始します。
  2. Layer A/Bで使用したTiling And Offsetの出力を、それぞれNormal用Sample Texture 2Dへ接続します。
  3. 各SampleのRGBAを別々のUnpack Normalへ接続します。
  4. 2つのUnpack Normal出力をAddし、Normalizeします。
  5. Lerp(World Normal, 合成Normal, NormalStrength)をNormalizeし、PBR SurfaceのNormalへ接続します。
Normal Sample A→ Unpack Normal↘ Add → Normalize→ Lerp(World Normal)→ PBR Normal

Unpack NormalはPrimitive頂点のTangent-to-World行列を使用してワールド法線へ変換します。そのため、Unpack前ではなくUnpack後にWorld Normalと混ぜます。

任意: Primitive Planeを小さく波打たせる

添付画像の模様を作るだけなら不要です。Planeのシルエットや反射を揺らしたい場合だけ追加してください。

公開パラメータとしてWaveAmplitudeを追加し、0.02から0.08程度で使用します。Primitive Planeの分割X/Yは32以上を推奨します。

  1. 右クリックの出力からVertexを追加します。
  2. Vertex用にUV、Time、Tiling And Offset、Texture Sampleを複製します。
  3. 2つのSample.RをAddし、0.5をMultiplyしてから0.5をSubtractします。値が約-0.5から0.5になります。
  4. 値 × WaveAmplitude × Object Normalを作ります。
  5. Object Positionへ加算し、VertexのPosition (Object)へ接続します。
  6. Object NormalとObject TangentはそのままVertexのNormal/Tangentへ接続します。
Height Samples→ -0.5 × Amplitude→ × Object Normal+ Object Position→ Vertex Position

現在は変位後の幾何法線を自動再計算しません。変位量を小さくし、Fragment側のWater Normalで細かい反射を表現する構成が安定します。

同じVertex出力はPrimitive2Dでも使用できます。画面演出用のPlane/Ringでは生成VSで変形されますが、ワールド水面にはPrimitive3Dを使用してください。

保存、Material生成、Entityへ適用

  1. 水面Entityをプレビューエンティティへ設定します。
  2. 保存してコンパイルを押します。
  3. waterSurface.material.jsonが同じフォルダへ生成されたことを確認します。
  4. 生成Materialを水面EntityのPrimitiveRendererへ設定します。
  5. PlayせずEdit中でもTimeを含むノードプレビューとMaterialプレビューを確認します。

TextureやColorを変更した場合は自動プレビューされます。ノードやグループの位置だけを移動した場合はShader再コンパイルされません。

C#からゲーム中に調整する

水面の移動時間はShader GraphのTimeが自動更新するため、毎フレームC#からTimeを設定する必要はありません。天候やゲームイベントで色・強度を変える場合だけMaterialInstanceを使用します。

using NEMEngine;

public sealed class WaterSurfaceController : ScriptBehaviour {
    [SerializeField] private PrimitiveRenderer waterRenderer;
    [SerializeField] private float calmIntensity = 0.8f;
    [SerializeField] private float activeIntensity = 1.4f;

    // Shader Graphの公開パラメータ欄に表示される16桁IDを設定する
    private static readonly MaterialParameterID CausticsIntensityID =
        MaterialParameterID.FromHex("ここへParameter ID");

    public void SetActive(bool active) {
        float intensity = active ? activeIntensity : calmIntensity;
        waterRenderer.MaterialInstance.SetFloat(
            CausticsIntensityID,
            "CausticsIntensity",
            intensity);
    }

    public void SetWaterColor(Color4 color) {
        waterRenderer.MaterialInstance.SetColor("ShallowColor", color);
    }
}
安定ID: Shader Graph公開パラメータを確実に更新する場合は、パラメータ欄からIDをコピーし、MaterialParameterID.FromHexを使用します。名前変更後も同じIDを維持できます。

Entity固有の値を元へ戻す場合はMaterialInstanceのClearを使用します。

添付画像へ近づける調整

線を細く、明るくする

Threshold ↑Softness ↓

Thresholdを0.6から0.75へ上げ、Softnessを0.05から0.1へ下げます。EmissiveStrengthは0.3前後から調整します。

大きくゆっくり揺らす

Tiling ↓LoopSeconds ↑

TilingAを(1,1)、TilingBを(2,2)にします。40秒ループならFlowを±0.025単位にします。

青を深くする

DeepColorRoughness

DeepColorのBを残してR/Gを下げます。Roughnessを0.08程度へ下げると水面反射が強くなります。

模様の反復感を減らす

Tiling 2 / 3逆方向Flow

Layer A/Bで互いに素な整数Tilingを使い、X方向を逆に流します。同じ位置で模様が重なる周期を長くできます。

処理負荷

  • 基本構成はコースティクスTextureを2回Sampleします。
  • Normalも2方向へ流すと合計4 Texture Sampleです。
  • Vertex変形でTextureを2回Sampleすると、Primitiveの各頂点段階にも追加負荷が発生します。
  • 大量の小さな水面ではNormal Layerを1枚に減らすか、Emissiveだけの簡易Materialを用意します。
  • Voronoiは1Sampleごとに周辺9セルを評価するため、Texture方式よりALU負荷が高くなります。
  • TimeはGPU側の共通定数で更新されるため、EntityごとのC# Updateは不要です。
推奨負荷構成: 大きな水面1から数枚なら、Caustics 2 Sample + Normal 2 Sample + Fresnelで問題ありません。多数の水面を表示する場合はCaustics 2 Sample + 幾何法線へ減らします。

したがって、添付画像のような「青い面に揺らぐ明るい焦線」は現在の機能で完成できます。一方、海洋シミュレーションや正確な水中屈折まで同じMaterialで実現するには追加機能が必要です。

トラブル対応

水面が真っ黒になる
  • CausticsTexture ParameterへTextureが設定されているか確認します。
  • ParameterノードがSample Texture 2DのTextureへ接続されているか確認します。
  • PBR SurfaceのBase Colorへ最終Addが接続されているか確認します。
  • 保存だけでなく保存してコンパイルを実行します。
  • 生成されたwaterSurface.material.jsonをRendererへ設定します。
模様が動かない

TimeノードのTime出力、MultiplyのFlow値、Fraction、Tiling And OffsetのOffsetを順に確認します。Flowが(0,0)なら動きません。

Textureの境界に線が出る

元Textureがシームレスでないか、Address U/VがMODE_CLAMPになっています。MODE_WRAPへ変更し、Textureの左右・上下が一致するか画像編集ツールで確認します。

20秒目で模様が飛ぶ

各Flow成分 × 20が整数か確認します。Rotateを使用して隣接Planeをまたいでいる場合はRotateを外してください。

焦線が面全体を白くする

Thresholdを上げます。Textureが白背景の場合はSample直後へOne Minusを追加します。CausticsIntensityとEmissiveStrengthも下げてください。

透明水面の描画順がおかしい

まずOpaqueへ戻してGraph自体を確認します。Transparentでは深度書き込みを無効にし、重なる透明面を必要以上に増やさないでください。

Normalの凹凸が逆に見える

Normal TextureのGチャンネル規約を確認します。必要ならSampleをSplitし、GへOne Minusを通してCombineした後、Unpack Normalへ接続します。

Vertex変形が見えない

Primitive Planeの分割X/Yが1では中央が曲がりません。両方を32にし、WaveAmplitudeを一時的に0.2程度へ上げて接続を確認します。Shader Graphの描画対象がPrimitive3Dであることも確認してください。

C#から値を変えても反映されない

Shader Graphパラメータの16桁IDをコピーし、MaterialParameterID.FromHexを使用します。PrimitiveRendererへ生成Materialが設定されていることも確認してください。

完成確認

  • 水面が黒ではなくDeepColorとShallowColorで表示される
  • Layer AとBが異なる方向へ動く
  • Texture境界と隣接Plane境界に継ぎ目がない
  • 20秒後のフレームが開始時と一致する
  • Thresholdで焦線の太さを調整できる
  • Fresnelが斜め方向で強くなる
  • Normalを有効にすると反射ハイライトが揺れる
  • OpaqueとTransparentのどちらを採用するか決定している
  • 保存してコンパイル後のMaterialをRendererへ設定している
  • Release用Shader Cookに生成MaterialとShader Graphが含まれる
最小完成条件: Caustics 2 Sample、Maximum、Smoothstep、Base Color、Roughness、Emissiveまで接続できれば、添付画像に近い揺らぐ水面として使用できます。NormalとVertex変形は後から追加できます。
