GPUパーティクルの確認手順

このページのチェックは、このブラウザーだけに保存されます。チェックが入っていない項目は未確認です。

最初の描画確認

  1. DevelopでNEMEditorを起動します。
  2. ProjectPanelからGameAssets/Scenes/Tests/GPU Particle Validation.scene.jsonを開きます。
  3. GameViewで床と複数の粒子を確認します。このSceneはPlayしなくても発生します。
  4. Hierarchyから各ParticleSystemを選び、停止・消去・再生、モジュールの強さ、色を変更します。

追従・衝突・描き込みをまとめて確認

  1. GameAssets/Scenes/Tests/GPU Particle Advanced Validation.scene.jsonを開きます。こちらもPlayしなくても動きます。
  2. 左のBrainStemがアニメーションし、水色の粒子が表面へ追従することを確認します。
  3. 中央の緑の粒子はGame Cameraの深度で衝突します。SceneViewだけを動かしても衝突面が変わらないことを確認します。
  4. 右の粒子が箱・床へ当たると、金色の子粒子、青い塗装、赤い命中跡が発生します。床または箱のParticlePaintReceiverComponentから塗装を消去できます。
  5. 「全体・GameCameraの色と深度から発生」を選ぶと、Camera表面からの発生を編集できます。このSystemが有効な間は、隠れたGameViewでも発生元のCamera入力を更新します。

スクリプトで順に確認

  1. 空のEntityにGPUParticleFeaturesDemoを追加します。既存のScene配置から離れた場所に置くか、新しいSceneを使ってください。
  2. Playし、GameViewへフォーカスを移します。確認用の床・Camera・ライト・粒子が実行中Worldに作られます。
  3. F8で次、Shift+F8で前の項目へ移動します。F9はInspector変更の反映と再放出、F10は塗装消去、F11は説明ログです。
  4. ScriptのInspectorで、発生元Mesh・Renderer・画像・FGA・マテリアルを指定できます。未指定でも標準の確認用データを使います。
  5. Stopで確認用の実行時Entityは破棄されます。ScriptはSceneの保存を行いません。

各機能の確認

ParticleSystemComponentの実行方式をGPUにして設定してください。モジュールは各フェーズから追加します。各モジュールの詳細欄の先頭にある「モジュールを有効にする」でON/OFFを切り替えられます。OFFでも設定値は保存され、詳細はグレー表示になります。切替時は構成を再反映して粒子を再生成します。

確認番号操作確認する結果
1頂点・辺から発生

GPU発生元 → 発生元を「頂点」または「辺」にし、メッシュを指定。「順番に発生」を切り替える。

頂点、または辺に沿って粒子が発生する。
2面から均等に発生

発生元を「表面」にする。大きさの異なる面を持つメッシュを指定する。

大きい面ほど多く発生し、面積あたりの密度が揃う。
3動く形状・スキニング

Renderer欄へHierarchyのMeshRendererを持つEntityをドロップ。「表面へ固定」を有効にして対象を動かす。

画面外でも形状が更新され、粒子が元の面に追従する。「移動速度を継承」は放出時の速度に作用する。
4画像・頂点カラーで発生を制限

「マスクを使う」を有効にし、マスク画像または頂点カラー、チャンネル、最小値・最大値を指定する。

指定範囲を満たす場所から発生する。元のShaderGraphと同じマスクを指定すれば消失演出と連動できる。
5画像・RenderTexture・Cameraから発生

発生元を画像またはCameraに変更する。Cameraは有効な3D Cameraを指定する。発生元に必要なCamera入力はGameViewを隠していても更新される。

画像平面、またはCameraの不透明な表面位置から発生する。Cameraは対応する前回の色・深度を使う。
7共有する力場

ForceFieldComponentを追加し、ParticleSystemにForceFieldモジュールを追加する。対象Layerを揃える。

吸引・反発・渦・風の設定で軌道が変わる。
8カールノイズ

CurlNoiseモジュールの強さ・周波数・移動速度を変更する。

粒子の流れに連続した渦が加わる。CPUでも利用可能。
9ベクトルフィールド

VectorFieldComponentのプリセットを渦または風にする。FGAを使う場合はAssetを指定する。

範囲内の粒子だけが場に沿って移動する。FGAの読込失敗は診断に表示される。
10曲線の移動・周回

SplineComponentを追加し、SceneViewで制御点を編集する。SplineMovementモジュールのSpline欄へドロップする。

弧長に沿って移動し、接線方向へ向く。周回半径を設定すると曲線の周囲を移動する。
12形状との衝突

Collisionモジュールを有効にし、SceneのColliderまたは平面を選ぶ。反射・停止・消滅を切り替える。

平面・球・箱・カプセルと衝突する。半径、反射率、摩擦が反映される。
13Cameraの深度との衝突

Collisionの深度を有効にし、Cameraを指定する。未指定ならメインGame Cameraを使う。

描画された不透明形状と衝突する。SceneViewの移動で衝突Cameraが変わらない。
14高さ画像との衝突

HeightmapColliderComponentに高さ画像を指定し、範囲・高さ倍率を設定する。CollisionのHeightmapを有効にする。

画像の凹凸に沿って衝突する。画像は線形の値として読み込まれる。
17イベントで別Systemを発生

GPUイベント → 発生経路を追加。発生先へ別のGPU ParticleSystemをドロップし、衝突・消滅・経過時間・フェーズ終了を選ぶ。

次の更新で子粒子が発生し、位置・法線・速度・色・Seedの選択が反映される。循環する経路は診断される。
18実行時の塗装

受け取り側にParticlePaintReceiverComponentを追加する。最初は平面XZ投影にし、粒子側の「塗装する」を有効にする。

衝突場所に色が蓄積する。元画像は変更されない。消去で戻り、Stop後に編集用Sceneへ残らない。
19衝突デカール

「デカールを残す」を有効にし、マテリアル・大きさ・保持秒数・フェード秒数を指定する。受け取り側のDecal受信も有効にする。

衝突した場所にGPUのPoolから投影され、粒子が消えた後も指定時間残る。
21Soft Particles

エミッターの表面設定で「深度に沿ってフェード」を有効にし、フェード距離を変更する。

床や壁との交差部分が柔らかく消える。
22受光・法線マップ

「ライトを受ける」を有効にし、法線テクスチャ、メタリック、ラフネスを設定する。

ライトと環境光で見た目が変わる。平行光源の影を受けられる。
29既存モジュールのGPU実行

色・サイズ・回転・UV・ノイズ・らせん・振り子・形状・発光などのモジュールをGPUで組み合わせる。

Phaseの順序、モジュールの順序、Curveとイージングが反映される。
30任意データ・マテリアルCurve

CustomDataモジュールを追加し、確認用Graphのマテリアルを指定する。Materialの数値を寿命Curveで変更する。

CustomData1/2がShaderGraphのParticleDataへ渡り、色や演出に使用できる。

組み合わせと寿命

  1. グラフィック設定のダブルバッファリングをON/OFFし、描画や動作が変わらないことを確認します。
  2. GameViewとSceneViewを並べ、それぞれのCameraを動かします。表示するViewの数で粒子の速度が変わらないことを確認します。
  3. Play → Pause → Resume → Stopを行い、古い塗装や子粒子が次のPlayに残らないことを確認します。
  4. Sceneを切り替え、古い残留デカール・塗装が残らないことを確認します。
  5. Entityの複製、Prefab保存と複数配置で、内部のSpline・Camera・イベント参照がそれぞれのInstanceを指すことを確認します。

対応範囲

  • Camera表面からの発生は、対応した前回の色・深度を使用します。Meshのような表面固定・速度継承は扱いません。
  • 深度衝突は画面内の不透明面が対象です。EntityとUVが得られないため、そのHitでの受け取り面への塗装には使えません。World位置への残留デカールには使えます。
  • 平面・球・箱・カプセルの衝突から塗装する場合は、受け取り側の投影を平面XZにします。UV投影にはUV付きのHitが必要です。
  • 塗装とデカールの色には、命中時の粒子の色が乗算されます。指定色をそのまま使う場合は、粒子のRGBを白にします。
  • 残留デカールはWorldに固定されます。移動するMeshへの接着ではありません。
  • Lit粒子の標準の影受けは平行光源のShadow Mapに対応します。
  • GPUイベントは見た目の処理です。C#へ粒子ごとの衝突通知は返しません。
  • イベント・塗装・デカールには上限があり、超過はInspectorの診断へ表示されます。
