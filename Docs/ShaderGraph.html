Visual material authoring

Shader Graph 完全ガイド

NEMEngineのShader GraphでSurface、Post Process、Ray Tracing Effectを作成し、Rendererへ適用してC#から動かすまでを一つにまとめたガイドです。記載内容は現在の実装とノードレジストリに合わせています。

1. Graphノードと公開パラメータを編集
2. Compile対象Renderer向けHLSLとメタデータを生成
3. Material生成された.materialへ既定値を保存
4. InstanceEntity固有値をInspector/C#で上書き

基本手順

  1. Toolパネルから「シェーダーグラフ」を開きます。
  2. 「作成種類」を選びます。通常のRenderer用は Surface です。
  3. Surfaceでは「作成対象」を Mesh、Primitive3D、Sprite、Text、Primitive2D、Particle、Trail から選びます。
  4. GameAssets以下の作成先を指定し、「新規作成」を押します。
  5. 空いている場所を右クリックし、ノードを作成して出力ノードへ接続します。
  6. 外から調整する値は「公開パラメータ」で作成し、右クリックの「パラメータ」からグラフへ置きます。
  7. 「保存してコンパイル」を押します。診断にエラーが出た場合は項目をクリックして対象ノードへ移動します。
  8. 生成された .material.json を対象Rendererのマテリアル欄へ設定します。
  9. Rendererの「シェーダーパラメータ」でEntity固有値を調整します。
保存と保存してコンパイルの違い「保存」はグラフJSONだけを保存します。見た目へ反映するには「保存してコンパイル」を使います。

エディター操作

作成と検索

キャンバスの空所を右クリックすると作成メニューが開きます。上部検索では英語ノード名と日本語カテゴリを検索できます。定数、既存の公開パラメータ、キーワードは専用サブメニューから追加します。

接続

出力ピンから入力ピンへドラッグします。型が違う数値同士はコンポーネント数に応じて変換されます。Texture2DとSamplerStateは対応する専用ピンへ接続します。

選択と整理

複数選択、コピー&ペースト、右クリック複製、削除、グループ化に対応します。グループ名は枠上部で編集でき、グループを動かすと所属ノードだけが追従します。

履歴

「元に戻す」「やり直す」はShader Graphパネルが操作対象のときだけ反応します。メインエディターのScene操作履歴とは分離されています。

ノードプレビュー

対応ノードは値やテクスチャ結果をノード内に表示します。右クリックの「プレビュー」から一括展開・折りたたみが可能です。

マテリアルプレビュー

SurfaceではプレビューEntityを設定できます。コンパイル済みマテリアルが対象Entityへ一時適用され、解除すると元のマテリアルへ戻ります。

見た目設定

背景・グリッド・スナップ間隔、ノード色・余白・文字スケール・最小幅、プレビュー表示サイズと解像度、リンク色・太さ・曲率・開始終了オフセットを調整できます。「保存」「読み込み」「元に戻す」はユーザー設定として管理されます。

設定項目

  • 名前: エディター上の表示名です。
  • 参照名: 生成HLSLで使う基礎名です。公開後の不用意な変更は避けます。
  • ID: UUID由来の安定IDです。C#から確実に変更する場合にコピーして使います。
  • Semantic: BaseColorTextureなど標準PBRの役割をエンジンへ伝えます。同じ意味を持つ標準Renderer処理と連携するときに設定します。
  • 更新単位: PerMaterialはマテリアル既定値、PerInstanceはEntity単位上書き、Globalは共有値を想定した分類です。
  • 公開: InspectorやSub Graphの入力として見せるかを決めます。
Texture2Dの基本Texture2DパラメータをParameterノードとして置いただけでは色になりません。Sample Texture 2DのTextureへ接続し、UVとSamplerを渡してRGBA/RGBを使います。

キーワード

BooleanまたはEnumで処理を切り替えます。「実行時切り替え」が無効なら既定値をHLSLへ埋め込み、変更時に再コンパイルします。有効ならMaterial Instanceの値として扱い、Branchなどへ接続して実行中に変更できます。

作れる表現と実装例

Spriteを上から0～1で消す

  1. Surface / Spriteのグラフを作成します。
  2. Float公開パラメータ discardAmount を作り、既定値0にします。
  3. UV → Split と接続し、Gを使います。
  4. 上から消す量へ合わせるため、discardAmount → One Minus を作ります。
  5. StepのAへOne Minus、BへUV.Gを接続します。結果は残す部分が1、消す部分が0になります。
  6. 元テクスチャのAとStep結果をMultiplyし、Unlit SurfaceのOpacityへ接続します。
  7. グラフ設定の「アルファクリップ」を有効にし、Alpha Clipへ小さい定数（例0.001）を接続します。
  8. Colorは Sample Texture 2D.RGBA × Tint を接続します。
向きが逆の場合UVの上下定義と目的が逆なら、UV.GまたはdiscardAmount側へOne Minusを追加します。

UVスクロール

Time.Time × Float2速度 → Tiling And Offset.Offset、UVをTiling And Offset.UVへ接続し、その出力をSample Texture 2D.UVへ渡します。ノイズを2枚、異なる速度・方向で流してMultiplyまたはLerpすると繰り返し感が減ります。

ディゾルブ

Simple NoiseまたはノイズテクスチャのRから公開Floatの閾値をSubtractし、Smoothstepで境界幅を作ります。結果をOpacityへ、Alpha Clipへ閾値を渡します。境界部分は二つのSmoothstepの差を取り、Emissive色へMultiplyすると発光する縁になります。

発光パルス

Time.Sine Time → Remap(-1,1→0,1) → Multiply(発光強度) → Emissive とします。色はColor公開パラメータをMultiplyします。

頂点を波打たせる

Mesh、Primitive3D、Primitive2DでVertex出力を追加します。Object Positionの成分とTimeをAddし、Sine、Multiply(振幅)へつなぎます。Object Normal×振幅をObject PositionへAddし、VertexのPositionへ接続します。法線を厳密に更新しない大変形ではライティングにずれが出るため、Normal/Tangentも設計します。

水・屈折

Transparent Surfaceにし、Screen Positionから画面UVを作ります。流れるノイズを小さい強度でUVへ加算し、Scene ColorをそのUVで読みます。水色とのLerp、Fresnel、Scene Depthとの差による水際色を合成します。Scene Colorを使うためOpaqueではコンパイルできません。

PBRマテリアル

BaseColorTextureをSampleしBase Colorへ、NormalTextureをSampleしてUnpack Normal経由でNormalへ、Metallic/Roughness/AOを各出力へ接続します。発光はEmissiveへHDR色または色×強度を渡します。

画面全体の色調整

PostProcessグラフでScene Colorを読み、Multiplyで色味を変え、Lerpで元色と調整色を公開Floatにより混ぜ、Post Process Colorへ接続します。

Ray Tracing Effect

World PositionをOrigin、反射方向をDirectionへ渡してTrace Sceneを実行します。HitをLerp係数にしてScene ColorとTrace Scene.Colorを合成します。Render Feature Profile側で実行位置と入力リソースを構成します。

C#から公開パラメータを制御

Shader Graphの公開パラメータはUUID由来IDです。名前からのハッシュではなく、エディターのパラメータ設定に表示される16桁IDをコピーし、MaterialParameterID.FromHexを使うのが確実です。

using NEMEngine;

public sealed class SpriteDiscard : Component {

    [SerializeField]
    private SpriteRenderer? target;

    private static readonly MaterialParameterID DiscardAmountID =
        MaterialParameterID.FromHex("97c2bd5c0942fb8e");

    private float amount;

    public override void Update() {
        amount = Math.Clamp(amount + Time.deltaTime * 0.4f, 0.0f, 1.0f);
        target?.MaterialInstance.SetFloat(
            DiscardAmountID, "discardAmount", amount);
    }
}

Texture2Dなら SetTexture、Colorなら SetColor、Vectorなら SetVector を使います。MeshRendererはサブメッシュ単位のMaterialInstanceも取得できます。

private static readonly MaterialParameterID NoiseTextureID =
    MaterialParameterID.FromHex("0123456789abcdef");

sprite.MaterialInstance.SetTexture(
    NoiseTextureID, "noiseTexture", noiseTexture);

// Entity固有の上書きを解除してMaterial既定値へ戻す
sprite.MaterialInstance.Clear(NoiseTextureID);
IDを使う理由公開パラメータの表示名を変更してもUUIDは維持されます。SetFloat("名前", ...)は通常HLSL名向けの名前ハッシュなので、Shader Graph公開パラメータではコピーしたIDを使用してください。

現在の対応範囲と設計上の注意

  • Surface対象はMesh、Primitive3D、Sprite、Text、Primitive2D、Particle、Trailです。
  • 頂点グラフはMesh、Primitive3D、Primitive2Dのみ対応します。
  • Scene Color / Depth / Normal / Position / Material / Emissive / FlagsはSurfaceではTransparentのみ使用できます。
  • Trace SceneはRayTracingEffectのみ使用できます。
  • ノードプレビューは最終Renderer結果そのものではありません。実機能確認はプレビューEntityまたはSceneView/GameViewで行います。
  • 大量のBranchや高コストなTrace Scene、複数テクスチャサンプルはGPU負荷になります。まず目的の見た目を作り、GPUプロファイルで確認します。
  • Sampler StateはSample Texture 2Dごとに分けられます。同じ設定はノードを複製・共有して重複を減らします。
  • 標準SemanticはRendererやPBRとの連携契約です。独自パラメータへ無理に標準Semanticを割り当てないでください。
