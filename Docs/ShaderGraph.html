NEMEngine Shader Graph

ノードを接続してSurfaceまたはPostProcess用HLSLとMaterialを生成する、現在のNEMEngine Shader Graph機能ガイドです。

対象: schemaVersion 4 / 2026-08-01時点の実装

概要

正本は.shadergraph.jsonです。保存してコンパイルすると、同じフォルダへ.material.jsonを作成し、再生成可能なHLSLとShader情報はLibrary/ShaderGraphへ出力します。

対応済み: 3D PBR、2D Unlit、Particle、Trail、Vertex変形、Scene Texture、ノードプレビュー、Entityプレビュー、Sub Graph、Custom Function、PostProcess Compute、Release用DXIL Cook。
注意: Shader GraphのSurfaceロジックをDXR Closest Hitへ共有する経路とMaterialごとのStatic Variant組み合わせ生成は未対応です。詳細は「現在の制限」を参照してください。

基本手順

  1. メニューバーのツールからシェーダーグラフを開きます。
  2. 作成種類をSurfaceまたはPostProcessから選びます。Surfaceでは作成対象も選びます。
  3. 作成先へGameAssets/...から始まる.shadergraph.jsonパスを入力し、新規作成を押します。
  4. キャンバスを右クリックし、定数、パラメータ、演算、UV、テクスチャなどのノードを追加して出力ノードへ接続します。
  5. 保存してコンパイルを押します。同名の.material.jsonが生成または更新されます。
  6. 生成Materialを対象Rendererへ設定します。SurfaceグラフではプレビューEntityを指定すると編集中の見た目も確認できます。
例: GameAssets/Materials/VFX/Dissolve.shadergraph.jsonを作成すると、Materialは同じ場所のDissolve.material.jsonになります。

Surface設定

  • 名前: グラフと生成Materialの表示名。
  • 既定精度: Inheritノードが参照するFloat/Half指定。現在はIRメタデータまでで、生成型は主にfloatです。
  • 描画対象: Rendererと生成PSの入出力契約を切り替えます。
  • サーフェス: OpaqueまたはTransparent。生成MaterialのRenderPhaseを決定します。
  • 描画状態: Blend、Cull、Fill、深度、ステンシル、アルファクリップ、Shadow設定を派生Pipelineへ反映します。
  • Sampler: Filter、Address U/V/W、比較、Border Color、Anisotropy、Mip LOD範囲を設定できます。

プレビューと見た目設定

ノードプレビュー

出力ノード以外はプレビューを展開できます。Texture、UV、演算、Noise、Timeの途中結果を同じキャンバス上で確認できます。Timeノードを含むプレビューはEdit中も更新されます。

MaterialプレビューEntity

Surfaceグラフでは、HierarchyのEntityをプレビューエンティティへ設定できます。MeshRenderer、PrimitiveRenderer、FillMeshRenderer、SpriteRenderer、TextRendererに対応し、解除時は元のMaterialへ戻します。

見た目設定

設定はユーザー設定へ保存され、Git管理するグラフアセットには入りません。

区分設定可能項目
キャンバス背景色、グリッド色。
ノード背景、通常/ホバー/選択境界線、範囲選択色、余白、文字スケール、最小幅、プレビュー表示サイズ、プレビュー解像度、角丸、各境界線幅。

再利用と拡張

Sub Graph

  1. 再利用したい処理を通常の.shadergraph.jsonとして作成します。
  2. 親グラフへSub Graphノードを追加し、左パネルの選択ノード設定で参照グラフを指定します。
  3. 子グラフの公開パラメータが入力ポート、子の出力ノード入力が親側の出力ポートになります。

コンパイル前に親グラフへ展開され、循環参照と参照失敗は診断されます。現在は専用.shadersubgraph.jsonではなくShader Graphアセットを参照します。

Custom Function

関数名、InlineまたはFile、入力ポート、出力ポートを設定できます。ポートの追加、削除、名前、型変更に対応します。

void DistortUV(float2 UV, float Time, out float2 Output) {
    Output = UV + float2(sin(UV.y * 12.0f + Time), 0.0f) * 0.03f;
}

Inlineでは関数定義全体を入力します。Fileでは生成HLSLから参照可能な.hlsliパスを指定します。

Keyword

BooleanとEnum、名前、参照名、既定値を保存できます。実行時切り替えが無効なら既定値をHLSLへ埋め込み、グラフ保存時に再コンパイルします。有効ならMaterialパラメータになり、InspectorまたはC#のMaterialInstance.SetBool/SetIntで切り替えられます。

実行時KeywordはShader Variantを増やさない代わりに動的分岐になります。同時に使う組み合わせが少なく固定できる表現は静的、ゲーム中に変える表現は実行時を選びます。

Materialと実行時処理

保存してコンパイルは次の処理を行います。

  1. Shader Graph JSONを保存。
  2. 型、リンク範囲、重複入力、循環、Stage互換をIRで検証。
  3. Surfaceなら共通Surface HLSLとOpaque/Transparent PS、PostProcessならCSを生成。
  4. Library/ShaderGraph/<Graph AssetID>/...へ派生ファイルを保存。
  5. 決定的な派生Shader AssetIDを生成してRenderAssetLibraryへ登録。
  6. 同名Materialを作成または更新。既存の同一グラフMaterial値は維持。
  7. プレビュー中ならPipelineをReloadしてEntityへ即時反映。

Materialロード時もshaderGraph参照を解決し、派生Shaderを登録します。Textureや色などのRenderer固有値はMaterial Instance Overrideとして扱います。

C#から公開パラメータを操作

各RendererのMaterialInstanceから名前またはParameter IDで値を変更できます。MeshRendererはサブメッシュ単位のGetMaterialInstance(index)も使用できます。

using NEMEngine;

public sealed class DissolveController : ScriptBehaviour {
    [SerializeField] private SpriteRenderer target;
    [SerializeField] private Texture noiseTexture;

    private static readonly MaterialParameterID DissolveID =
        MaterialParameterID.FromHex("グラフ上でコピーしたParameter ID");

    public override void Start() {
        target.MaterialInstance.SetTexture("NoiseTexture", noiseTexture);
    }

    public override void Update() {
        float amount = (MathF.Sin(Time.time) + 1.0f) * 0.5f;
        target.MaterialInstance.SetFloat(DissolveID, "Dissolve", amount);
    }
}

使用可能な主なAPIはSetFloat、SetVector、SetColor、SetTexture、SetInt、SetUInt、SetBool、対応するTryGet...、Clearです。

作成できる表現・演出・Material例

以下は現在のShader Graphにあるノードだけで構成できる代表例です。矢印は主な接続順を表し、色や速度などを公開パラメータにするとMaterialまたはC#から調整できます。

WetMask -> Lerp(DryColor, DryColor * 0.55) -> Base Color

Lerp(0.75, 0.08, WetMask)

PostProcess演出

画面フェード・色フラッシュ

PostProcessScene Color

Scene Colorと指定色をLerpします。シーン遷移、被弾、回復、警告に利用できます。

Scene Color -> Lerp(SceneColor, EffectColor, Amount) -> Post Process Color
公開値
EffectColor、Amount

画面UV歪み・熱気

PostProcessNoise

NoiseでScene Colorへ渡すUVを少量ずらし、熱気、水中、ダメージ時の揺れを作ります。

UV + (Noise(UV + Time) - 0.5) * Strength -> Scene Color -> Output
公開値
Strength、Scale、Speed
注意
歪み量を大きくしすぎると画面端のSampleが目立ちます

グレースケール・色調変更

PostProcessDot

Scene Colorと輝度係数のDotで明度を作り、元色とLerpします。

Dot(SceneColor.RGB, Luminance) -> Lerp(SceneColor, Gray, Amount) -> Output
公開値
Amount、TintColor、Contrast
Scene Texture: Transparent SurfaceとPostProcessではScene Color、Depth、Normal、Position、Material、Emissive、Flagsを参照できます。Opaque Surfaceから同じ描画先を読む構成は循環を避けるため使用できません。

ノイズとVFX

自分で用意しなくても使用できます。 グラフ内生成のSimple Noise / Voronoiと、エンジン標準の30枚のNoise Textureがあります。

プロシージャルノイズ

Texture不要でScaleを自由に変えられます。Simple NoiseはValue Noise、Voronoiはセル境界や粒状表現に向きます。

向く用途: 小規模なディゾルブ、揺らぎ、輪郭、試作。

注意: 多数の描画対象で重ねるとTexture SampleよりALU負荷が高くなります。

Noise Texture

Project/Engine/Assets/Textures/DefaultEffect/Noiseにnoise_0.pngからnoise_29.pngがあります。

向く用途: 大量Sprite、Particle、Trail、複数ノイズ合成、形状を固定したい表現。

注意: 全画像のシームレス性、Blue Noise特性、方向場は保証されません。

Noise Textureの使い方

  1. 公開パラメータを追加し、型をTexture2D、名前をNoiseTextureにします。
  2. 既定値へProject/Engine/Assets/Textures/DefaultEffect/Noise/noise_*.pngを設定します。
  3. ParameterノードとSample Texture 2Dノードを追加し、ParameterをTexture入力へ接続します。
  4. UVをTiling And Offsetへ接続し、出力をSample Texture 2DのUVへ接続します。
  5. Timeに速度を掛けた値をOffsetへ加算するとスクロールします。
  6. SampleのRをSmoothstepまたはStepへ入れ、Dissolve値と比較してAlpha Clipへ接続します。

VFX向け構成例

ディゾルブ

Noise.R - DissolveをSmoothstepへ入れ、Base ColorのAlphaまたはAlpha Clipへ接続します。境界だけを別Smoothstepで抜き、Emissiveへ加えると発光縁になります。

流れるエネルギー

同じNoise TextureをTilingの異なるUVで2回Sampleし、一方を逆方向へスクロールします。MultiplyまたはMinimumで合成し、ColorとEmissiveへ接続します。

煙・炎

Polar Coordinatesまたは縦方向UVへNoiseを加えて形状を歪めます。Timeで上方向へ流し、下から上へ薄くなるマスクをMultiplyします。

衝撃波・リング

Polar Coordinatesの半径へTimeを加え、FractionとSmoothstepで細い帯を作ります。Noiseを掛けて輪郭を崩し、Emissiveへ出力します。

自作Textureが必要になるケース

  • 完全にシームレスなループが必要。
  • Blue Noise、Curl Noise、Flow Map、法線Noiseが必要。
  • 炎、雷、煙など特定方向へ流れる形を作りたい。
  • 複数チャンネルへ異なるNoiseをパックし、Sample回数を減らしたい。
  • ゲーム固有の輪郭や手描き表現が必要。

標準Noise Texture一覧

PostProcess Graph

  1. 作成種類をPostProcessにしてグラフを作成します。
  2. Scene ColorのUVへ必要なUVを接続し、RGBAを演算してPost ProcessのColorへ接続します。
  3. 保存してコンパイルし、生成されたCompute MaterialをPostProcess Stackのパスへ設定します。
  4. PostProcess Stack側でAnchor、入力パス、出力、他パス参照を設定します。

生成CSは[numthreads(8, 8, 1)]で動作します。Scene Colorに加えてDepth、Normal、Position、Material、Emissive、Flagsを選択したUVから参照できます。

トラブル対応

Materialを設定すると何も描画されない
  • グラフの描画対象とRenderer種類が一致しているか確認します。
  • 保存してコンパイルを行い、通常保存だけで終わっていないか確認します。
  • Base ColorまたはColorが0、Opacityが0、Alpha Clipが高すぎないか確認します。
  • Project/Log/engine.logのShader Compile Errorを確認します。
Textureが黒またはエラーTextureになる
  • Texture2Dパラメータに既定Textureが設定されているか確認します。
  • ParameterノードがSample Texture 2DのTexture入力へ接続されているか確認します。
  • Material側で同名パラメータを別値で上書きしていないか確認します。
ノード接続が拒否される

入力に複数リンクがないか、Texture2Dと数値を接続していないか、Fragment専用ノードをComputeへ接続していないか確認します。

UndoやDeleteが別パネルへ作用しない

仕様です。Shader Graphの編集コマンドはShader Graphがフォーカス中の場合だけ反応します。SceneのEntity操作はSceneView、GameView、Hierarchy、Inspector側へフォーカスを移してください。
