NEMEngine C# スクリプティング API ガイド

ゲーム制作でよく使う C# API のまとめ。すべて namespace NEMEngine に属する。

1. はじめに

ゲームの挙動は ScriptBehaviour を継承したクラスに書く。クラスは partial でなくてよく、 public sealed class 推奨。ファイル先頭で using NEMEngine; を書き、自前の namespace（例 SandboxScripts）に置く。 

using NEMEngine;

namespace SandboxScripts;

public sealed class MyScript : ScriptBehaviour
{
    public override void Update()
    {
        Debug.Log("毎フレーム呼ばれる");
    }
}

スクリプトはエンティティへコンポーネントとして付与する。インスペクターに公開した値は [SerializeField] 付きのフィールドで設定でき、シーンへ保存される。スクリプトを保存すると エディターが自動でリロード（ホットリロード）する。

ヒント: transform と entity は ScriptBehaviour が標準で持つ。自分が付いているエンティティを指す。

2. ライフサイクル

ScriptBehaviour の virtual メソッドを override して使う。呼ばれる順序は次の通り。

メソッド呼ばれるタイミング
Awake()生成直後に1回。参照の初期化向け。
OnEnable()有効化された時。
Start()最初の Update 前に1回。
FixedUpdate()固定ステップ毎。物理向け。Time.fixedDeltaTime を使う。
Update()毎フレーム。通常のゲームロジック。
LateUpdate()全 Update の後。カメラ追従など。
OnDisable()無効化された時。
OnDestroy()破棄される時。後始末向け。
OnCollisionEnter/Stay/Exit(Collision)衝突の開始/継続/終了。詳細は 11章。

有効/無効は Enabled プロパティで制御できる。IsActiveAndEnabled は階層が active かつ自身が有効な時に true。

3. 属性一覧

フィールドに付ける属性。インスペクター表示やシリアライズの挙動を変える。

属性説明
[SerializeField]private フィールドをインスペクターに公開し、シーンへ保存する。
[Header("見出し")]フィールドの上に見出しを表示する（表示専用）。
[Tooltip("説明")]ホバー時に説明を表示する（表示専用）。
[Range(min, max)]数値をスライダー表示し、範囲内へ制限する。
[Min(min)]数値の下限を設定する。
[DragSpeed(speed)]数値ドラッグ編集の速さを設定する。
[Multiline]string を複数行で編集する。
[ReadOnly]表示はするが編集不可。値は保存される。
[HideInInspector]インスペクターに出さないが値は保存される。
[DefaultExecutionOrder(order)]スクリプトの実行順を制御する（小さいほど先）。クラスに付ける。
// インスペクターに公開、見出しと範囲制限つき
[Header("移動設定")]
[SerializeField, Range(0.0f, 20.0f)]
private float moveSpeed = 5.0f;

[SerializeField, Tooltip("発生させる Prefab")]
private AssetRef<PrefabAsset> bullet;

4. 入力

静的クラス Input から取得する。状態は毎フレーム更新される。

キーボード

API説明
Input.GetKey(KeyCode)押されている間 true。
Input.GetKeyDown(KeyCode)押した瞬間のフレームのみ true。
Input.GetKeyUp(KeyCode)離した瞬間のフレームのみ true。

KeyCode 例: W A S D, Space, Return, Escape, LeftShift, LeftArrow など。

マウス

Input.GetMouseButton/Down/Up(MouseButton)左=Left 右=Right 中=Middle。int 版(0/1/2)もあり。
Input.mousePosition / mouseDelta / mouseWheel位置・移動量・ホイール量。

ゲームパッド

Input.leftStick / rightStickスティック入力 (Vector2)。
Input.leftTrigger / rightTriggerトリガー (0..1)。
Input.GetGamepadButton/Down/Up(GamepadButton)ボタン状態（index 0 の単一パッド）。
Input.isGamepadConnected接続有無。
Input.GetGamepadButton(index, GamepadButton)多パッド版（最大4台）。GetGamepadAxis(index, GamepadAxis) も。

その他

Input.TextInput（このフレームの確定文字列）、Input.HasFocus（ウィンドウフォーカス）。

public override void Update()
{
    // WASD で入力ベクトルを組む
    Vector2 input = Vector2.zero;
    if (Input.GetKey(KeyCode.W)) { input.y += 1.0f; }
    if (Input.GetKey(KeyCode.S)) { input.y -= 1.0f; }

    // ゲームパッド左スティックを加える
    input.x += Input.leftStick.x;

    // ジャンプはトリガー（押した瞬間）で判定
    if (Input.GetKeyDown(KeyCode.Space)) { Jump(); }
}

5. Transform 操作

transform プロパティから位置・回転・スケール・親子関係を操作する。

メンバ説明
position / rotationワールド座標・ワールド回転（読み書き）。
localPosition / localRotation / localScaleローカル SRT（読み書き）。
forward / right / upワールド回転基準の方向ベクトル（読み取り）。
lossyScaleワールドスケール近似（読み取り）。
parent / SetParent(Transform)親の取得・設定。
SetParent(Entity, worldPositionStays=true)付け替え。true で見た目を維持する。
childCount / GetChild(index)子の数・index 番目の子。
// 前方へ移動し、進行方向へ向く
transform.position += transform.forward * (speed * Time.deltaTime);

// Y 軸ヨーを目標へ滑らかに補間
Quaternion target = Quaternion.FromEulerDegrees(new Vector3(0, yaw, 0));
float t = 1.0f - Math.Exp(-12.0f * Time.deltaTime);
transform.rotation = Quaternion.Slerp(transform.rotation, target, t);

6. 時間 (Time)

API説明
Time.deltaTime前フレームからの経過秒（TimeScale 適用後）。移動量に掛ける。
Time.UnscaledDeltaTimeTimeScale を無視した経過秒（ポーズ中も進む）。
Time.fixedDeltaTime固定ステップ間隔。FixedUpdate で使う。
Time.TimeScale全体の時間倍率。0 でポーズ相当（読み書き）。
Time.TimeSinceStartup / FrameCountPlay 開始からの経過秒・フレーム数。
// ポーズ切り替え
Time.TimeScale = paused ? 0.0f : 1.0f;

7. インスタンス生成

Prefab の生成は Prefab.Instantiate を使う。生成対象は AssetRef<PrefabAsset> 型の [SerializeField] フィールドに用意し、インスペクターで .prefab を割り当てる。

オーバーロード説明
Instantiate(prefab)原点に生成。
Instantiate(prefab, position, rotation)指定の位置・回転で生成。
Instantiate(prefab, position, rotation, parent)さらに親 Entity を指定して生成。
仕組み: 生成はコマンドバッファ経由で遅延適用される。ルート Entity は即時に返るが、コンポーネントの実体化は次の flush で行われる。
[SerializeField]
private AssetRef<PrefabAsset> bullet;

private void Fire()
{
    // 未割り当てなら何もしない
    if (bullet.IsNull) { return; }

    // 自分の位置・向きで生成する
    Entity spawned = Prefab.Instantiate(bullet, transform.position, transform.rotation);
}

8. Entity の破棄

Destroy(Entity)指定の Entity を破棄する（遅延適用）。
DestroySelf()自分の Entity を破棄する。
entity.Destroy()Entity から直接破棄する。
// 一定時間後に自分を消す
private float life = 3.0f;
public override void Update()
{
    life -= Time.deltaTime;
    if (life <= 0.0f) { DestroySelf(); }
}

9. コンポーネント取得

同じ Entity（や子孫・祖先）のコンポーネントや他スクリプトを取得する。ScriptBehaviour のメソッドとして使える。

API説明
Get<T>() / TryGet<T>(out T)コンポーネントを取得 / 安全に取得。
Has<T>()保有判定。
Add<T>() / Remove<T>()追加 / 削除。
GetInChildren<T>() / GetInParent<T>()子孫 / 祖先から探索取得。
GetComponent<TScript>()同 Entity の別 C# スクリプトを取得（Unity の GetComponent 相当）。
GetComponentInChildren/InParent<TScript>()子孫 / 祖先のスクリプトを取得。

取得できるコンポーネント型の例: MeshRenderer, SpriteRenderer, TextRenderer, AudioSource, SkinnedAnimation, PerspectiveCamera, OrthographicCamera, DirectionalLight, PointLight, SpotLight, UVTransform。

// 同じ Entity の別スクリプトを参照する
PlayerHealth? health = GetComponent<PlayerHealth>();
if (health != null) { health.TakeDamage(10); }

// コンポーネントを安全に取得して書き換える
if (TryGet<SpriteRenderer>(out var sprite))
{
    // sprite の値を編集する
}

10. シーン遷移

シーンは SceneManager で加算ロード／アンロードする。読み込むシーンは AssetRef<SceneAsset> で指定する。別シーンへ「切り替える」には、 次のシーンを LoadAdditive し、現在のシーンのハンドルを Unload する。

API説明
SceneManager.LoadAdditive(AssetRef<SceneAsset>)シーンを加算ロードし SceneHandle を返す（適用は次の flush）。
SceneManager.Unload(SceneHandle)シーンインスタンスをアンロードする。
SceneManager.SceneLoaded / SceneUnloadedロード／アンロード完了イベント。
SceneHandle.IsValidインスタンスがまだ存在するか。
[SerializeField]
private AssetRef<SceneAsset> nextScene;

private SceneHandle loaded;

private void GoNext()
{
    // 次のシーンを読み込む。完了は SceneLoaded で受け取れる
    loaded = SceneManager.LoadAdditive(nextScene);
}

public override void Start()
{
    SceneManager.SceneLoaded += OnSceneLoaded;
}

private void OnSceneLoaded(SceneEvent e)
{
    Debug.Log("シーン読み込み完了");
}
注意: ロード／アンロードは即時ではなく、次の flush で適用される。完了を待つ処理はイベントか SceneHandle.IsValid で確認する。

11. 衝突コールバック

CollisionComponent を持つ Entity 同士が当たると、スクリプトの衝突コールバックが呼ばれる。 当たり判定のタイプ（Layer）は CollisionManager で定義し、インスペクターで割り当てる。

OnCollisionEnter(Collision)接触した瞬間。
OnCollisionStay(Collision)接触している間。
OnCollisionExit(Collision)離れた瞬間。

Collision の主なフィールド: entity（相手）, self（自分）, normal, point, penetration, isTrigger。

public override void OnCollisionEnter(Collision c)
{
    // 相手の名前で分岐する
    if (c.entity.name == "Enemy")
    {
        Debug.Log("敵に接触");
    }
}

12. コルーチン / タイマー

コルーチン

IEnumerator を StartCoroutine で起動する。yield return で待機できる。

WaitForSeconds(秒)スケール適用時間で待つ。
WaitForSecondsRealtime(秒)実時間で待つ（ポーズ無視）。
WaitForFixedUpdate()次の FixedUpdate まで待つ。
WaitForEndOfFrame()フレーム終端まで待つ。
using System.Collections;

public override void Start()
{
    StartCoroutine(Blink());
}

private IEnumerator Blink()
{
    while (true)
    {
        Debug.Log("点滅");
        yield return new WaitForSeconds(0.5f);
    }
}

タイマー

ScheduleTimer(秒, Action)指定秒後に1回呼ぶ。
ScheduleRepeatingTimer(間隔, Action)一定間隔で繰り返す。
ScheduleUnscaledTimer(秒, Action)実時間で1回呼ぶ。
// 2秒後に発火する
ScheduleTimer(2.0f, () => Debug.Log("2秒経過"));
自動停止: コルーチン・タイマーは owner（このスクリプト）の破棄、Play 停止、DLL リロードで自動的に停止する。

13. ログ出力

Debug.Log(message)情報ログ。
Debug.LogWarning(message)警告ログ。
Debug.LogError(message)エラーログ。

14. 実践サンプル

WASD ／ゲームパッドで移動し、進行方向へ滑らかに向き、スペースで Prefab を生成するプレイヤー。

using NEMEngine;

namespace SandboxScripts;

public sealed class PlayerAction : ScriptBehaviour
{
    [Header("移動")]
    [SerializeField] private float moveSpeed = 5.0f;
    [SerializeField] private float rotationLerpRate = 12.0f;
    [SerializeField] private float stickDeadZone = 0.2f;

    [Header("生成")]
    [SerializeField] private AssetRef<PrefabAsset> sphere;

    public override void Update()
    {
        CreateObject();
        Move();
    }

    private void CreateObject()
    {
        if (Input.GetKeyDown(KeyCode.Space) && !sphere.IsNull)
        {
            Prefab.Instantiate(sphere, transform.position, transform.rotation);
        }
    }

    private void Move()
    {
        Vector2 input = Vector2.zero;
        if (Input.GetKey(KeyCode.W)) { input.y += 1.0f; }
        if (Input.GetKey(KeyCode.S)) { input.y -= 1.0f; }
        if (Input.GetKey(KeyCode.D)) { input.x += 1.0f; }
        if (Input.GetKey(KeyCode.A)) { input.x -= 1.0f; }

        Vector2 stick = Input.leftStick;
        if (stickDeadZone < stick.length) { input.x += stick.x; input.y += stick.y; }

        float len = input.length;
        if (len <= 0.0001f) { return; }
        if (1.0f < len) { input = input.normalized; len = 1.0f; }

        Vector3 dir = Vector3.Normalize(new Vector3(input.x, 0.0f, input.y));
        transform.position += dir * (moveSpeed * len * Time.deltaTime);

        float yaw = Math.RadToDeg(Math.Atan2(dir.x, dir.z));
        Quaternion target = Quaternion.FromEulerDegrees(new Vector3(0.0f, yaw, 0.0f));
        float t = 1.0f - Math.Exp(-rotationLerpRate * Time.deltaTime);
        transform.rotation = Quaternion.Slerp(transform.rotation, target, t);
    }
}
